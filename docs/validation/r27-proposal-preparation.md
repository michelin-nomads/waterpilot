# R27 Proposal preparation

Date: 2026-10-16

Proposal preparation from `/proposals/new?reportId=...` now has Summary, Budget
and Documents tabs. A `schemeId` from an eligible, verified funding match
preselects the curated scheme. The Budget tab reads exact minor-unit figures
from the finalized report only; proposal wording cannot rewrite them. Documents
lists the selected scheme's checklist and clarifies that attachment and external
submission are not automatic. Existing durable job navigation and private
proposal HTML/PDF artifacts remain the output path.

Browser visual inspection and opening a generated PDF remain unverified here.
The current Playwright Chromium binary is missing. Typecheck/lint/format/build
and bundle-budget results are recorded after this screen's checks. No live
services were called.
