# WaterPilot — Funding proposal drawer refinement

Design-only preview. Open index.html and choose a funding opportunity. Selection → proposal choice → prefilled form → generation progress → proposal review/download → submission guide all stay in the same right-side modal without changing the URL.

Use Back inside the modal to revise details. Close returns to the underlying funding list. All schemes, amounts and documents are illustrative; exports and source links are placeholders. No real application code or records were changed.

The Take Action preview contains the same funding/proposal modal flow and the complete report review design. See ../take-action-v1/README.md for behavior and data rules.
